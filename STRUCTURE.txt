Configuration Hierarchy
-----------------------
1. source-code/config.xml          — Enables/disables modules (master registry)
2. <module>/config.xml             — Port range + which instances are active/standby
3. <module>/<instance>/config.xml  — Instance data source, socket, DB, output paths

To activate a standby instance:
  1. Open the module's config.xml
  2. Set active="false" → active="true" on the target instance
  3. For countries module: also set enabled="false" → enabled="true" in source-code/config.xml

Build Scripts
-------------
build.sh   — Linux:   compiles source-code/**/*.java against jars/**/*.jar, packages Brarner.M.Alete.jar
build.bat  — Windows: same for Windows environments

Output: Brarner.M.Alete.jar (root directory)
Dependencies: jars/ (subdirs: ai/, chemistry/, java-fx/, json/, logging/, signal-processing/)

Maven (pom.xml)
---------------
Root pom.xml manages: projects, primary-source, servlets, ejbs, ear
Compiler target: Java 9
Dependencies: jdsp 3.1.1, fastjson 2.0.60 (both declared inside <dependencies>)

NIO Masquerade Layer
--------------------
configuration/nio-masquerade-config.xml  — NIO settings, port range mode, managed ports
configuration/masquerade-modules.xml     — Module registry for auto-discovery
Bridges NIO connections (port 2000) to BMA blocking socket architecture.
